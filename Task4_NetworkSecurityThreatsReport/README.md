# Task 4 — Research Report: Common Network Security Threats

## Objective
Write a comprehensive, well-structured research report on common network security threats — how each works, real-world impact, and mitigation strategies.

📹 No demo video required — this is a research/report task.

## Checklist

- [ ] Report saved as `network_security_threats_report.md`
- [ ] Introduction: why network security threats matter today (1 paragraph)
- [ ] DoS/DDoS Attacks: explanation, real-world example, impact, 3 mitigations
- [ ] Man-in-the-Middle (MITM) Attacks: explanation, real-world example, impact, 3 mitigations
- [ ] IP Spoofing: explanation, real-world example, impact, 3 mitigations
- [ ] DNS Poisoning/Spoofing (bonus): explanation, real-world example, impact, 3 mitigations
- [ ] Comparison table: attack vector / who's at risk / difficulty / ease of mitigation
- [ ] Conclusion: 3 key takeaways for a network administrator
- [ ] References: at least 4 credible sources (NIST, CISA, academic, reputable security pubs)

## Suggested Sources
- NIST (nist.gov), CISA (cisa.gov), SANS Institute (sans.org/reading-room)
- MITRE ATT&CK (attack.mitre.org) for technical descriptions
- Krebs on Security / Wired for real-world case examples
